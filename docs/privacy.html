Privacy Policy

Last updated: August 13, 2026

1. Overview

KhanClipping-Engine is a personal automation tool operated by a single individual for their own TikTok accounts. It is not a multi-tenant product; no third-party end users create accounts or submit data through it.

2. Data We Handle

This tool stores TikTok OAuth access tokens and refresh tokens for the operator's own connected TikTok accounts. Those tokens are stored in a private database and used solely to authenticate API requests to TikTok on the operator's behalf. No data belonging to TikTok viewers or other third parties is collected.

3. Third-Party Services

This tool integrates with the following third-party services. Each processes data according to its own privacy policy:

  • Anthropic — script generation
  • ElevenLabs — voice synthesis
  • Renderly — video rendering
  • AWS S3 — file storage
  • TikTok API — publishing

4. Data Retention

OAuth tokens are retained only as long as needed to operate the connected accounts and are deleted if an account is disconnected.

5. Data Security

Tokens and credentials are stored using standard access controls. No payment or government ID data is collected or stored anywhere in this system.

6. Contact

Questions about these terms can be directed to the operator through the contact information associated with the developer account under which this application is registered.
